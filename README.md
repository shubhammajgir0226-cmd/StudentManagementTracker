# StudentManagementTracker
The Student Grade Tracker is a Java-based application designed to manage and analyze student academic performance efficiently. The main objective of this project is to simplify the process of storing student marks, calculating averages, and identifying the highest and lowest scores.

This project allows users to enter student details and their grades, store the data using arrays or ArrayLists, and generate a summary report of student performance. It calculates the average marks of students and helps identify the students with the highest and lowest scores. The application uses basic Java programming concepts, including variables, loops, conditional statements, arrays, and ArrayLists.

The project is designed with a simple, user-friendly console-based interface that makes it easy to enter data and view results. It also helps improve programming logic, data management, and problem-solving skills.

Key Features:

Add and manage student grades.
Calculate average marks.
Find the highest and lowest scores.
Store and process student data using arrays or ArrayLists.
Generate a student performance summary report.
Display results through a console-based interface.

Technologies Used: Java, Core Java, Arrays, ArrayLists, and Object-Oriented Programming (OOP).

Conclusion: This project demonstrates the practical application of Java programming concepts to solve a real-world problem in student grade management.
